# next-one 작업 인수인계 (다른 Mac에서 이어서 작업하기)

> 마지막 정리: 2026-11-19 · 최신 커밋 `4432135` 기준
> 배포: https://andy-room.github.io/prototype/next-one/ (main에 푸시하면 1~2분 뒤 반영)

이 문서는 Claude Code와 함께 진행한 `next-one` 프로토타입 작업의 맥락·규칙·현재 상태를 담고 있어요. 새 Mac에서 저장소를 받은 뒤 Claude Code에게 "next-one/HANDOFF.md 읽고 이어서 작업하자"라고 하면 바로 이어 갈 수 있어요.

---

## 1. 시작하기

```bash
git clone https://github.com/andy-room/prototype.git
cd prototype
python3 -m http.server 8765 --bind 127.0.0.1
# 브라우저: http://localhost:8765/next-one/index.html
```

- 빌드 없음. 정적 HTML 하나(`next-one/index.html`, CSS·JS 모두 안에 있음)
- 직무 데이터: `skill-galaxy/type1/jobs.js` (index.html이 `../skill-galaxy/type1/jobs.js`로 불러옴)
- 이미지: `next-one/avatars/*.png`(a1~a10 내 아바타, p1~p12 다른 사람), `next-one/qr.png`
- Claude Code 미리보기 설정: `.claude/launch.json`의 `prototype-static`(포트 8765)

## 2. 작업 규칙 (사용자와 합의한 방식)

- **모든 답변·설명은 한국어.**
- 사용자가 "먼저 볼게요" → 로컬에서 열어 보게 함(커밋 안 함). "푸시" / "바로 푸시" → 커밋 후 `origin main`에 푸시. **말없이 푸시하지 않기.**
- 커밋 메시지: `next-one: 변경 요약` 형식, 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
- "PC MO 모두" = 데스크탑과 모바일 둘 다 같은 동작·같은 UI. 사용자는 **지금의 UI 스타일과 틀을 매우 좋아함** → 새 스타일을 만들지 말고 기존 틀(클래스)을 재사용해서 톤·무드를 맞출 것.
- 고친 뒤에는 브라우저에서 직접 확인하고 결과를 짧게 보고.
- 다른 사람에게 줄 단독 HTML이 필요하면: 아바타·QR을 base64로, jobs.js를 인라인으로 넣어 `next-one-standalone.html` 생성(커밋 안 함, "다시 뽑아줘"로 요청).

## 3. 서비스 컨셉 (판단 기준)

- **커리어를 향해 달려가며 거리를 좁힌다.** 커리어는 키워드로 검색해서 '목표'로 정함. "나는 이 직무다"라고 규정하지 않음.
- **지금의 나는 중요하지 않음.** 현재 직업·연차 표기 금지. 다른 사람도 "어디로 달리는 중"으로 보여 줌.
- **방향마다 프로필**(넷플릭스 프로필처럼). 프로필 하나 = 목표 하나. 무료는 기본 1 + 추가 1.
- **가치 사슬:** 콘텐츠(강의) → 스킬 → 커리어. 구독 모델이라 결국 콘텐츠를 소비하게 만드는 것이 목표.
- **핵심 원칙:** 사용자는 "다음 거 하나"만 누르면 됨(듀오링고식).
- **스킬에는 최대값이 없음.** 칸·게이지가 아니라 계속 쌓이는 포인트(+P). '도달점 있음/없음' 두 보기를 좌상단 옵션으로 비교(기본은 포인트 보기).
- **업데이트의 '손맛':** 강의를 마치면 "업데이트할 수 있는 스킬이 있어요" → 꾹 눌러 업데이트(서클이 다 돌면 갤럭시 빅뱅).
- **온톨로지가 빛나는 3순간:** 규모의 놀람(26,559개 중 N개) · 연결의 발견(내 스킬이 다른 직무에서도 쓰임) · 자유 입력 알아듣기.
- 문구 원칙: '완성도', '채워야 할 스킬'처럼 단정하는 말 금지. '남은 거리', '거리를 좁혀요' 같은 열린 말.
- 멤버십 혜택: 연관 스킬 직접 추가 · 같은 스킬 키우는 사람 더 보기 · 강의 연속 더 듣기(무료는 연속 3개) · 방향(프로필) 여러 개.

## 4. 화면 구조 (index.html 안)

| 화면 id | 내용 |
|---|---|
| `s-login` | 홈(마케팅/큐레이션). 커리어(프로필)에 따라 콘텐츠가 바뀜(`HOME_SET`) |
| `s-auth` | 로그인 화면. 제목 `#authH`는 상황에 따라 바뀜(`needLogin`) |
| `s-profile` / `s-avatar` / `s-dest` | 프로필 고르기 / 아바타 / 목표 찾기(커리어 키워드 검색) |
| `s-route` | 마이클래스(대시보드): 포인트, 내 스킬 목록(필터·편집) |
| `s-detail` | 메뉴 화면(콘텐츠·스킬·스킬 상세·사람 등)을 `paint()`로 그림 |
| `s-content` | 모바일 강의 재생 + 끝 시트(`cSheet`) + 꾹 누르기 업데이트 시트(`sheet`) |

- **상태:** 전역 `S` (`S.nav` 탐색 스택, `S.pid` 현재 프로필, `S.skills/S.extra/S.added`, `S.pend` 모은 포인트, `S.loggedIn`, `S.entered`)
- **프로필 데이터:** `PACKS.dpm`(데이터 PM), `PACKS.svc`(서비스 기획자). 나머지 커리어는 jobs.js 키워드로 임시 스킬 생성(`gSkill`)
- **데스크탑:** 왼쪽 레일 + 폰 칸(PH) + 오른쪽 2단 패널(XP, `#xp`) + 스킬 갤럭시(canvas `Galaxy`). `renderDesk()`가 nav[0]은 PH, 더 깊은 단계는 XP에 그림. 넓게 보기(`pmax`)면 XP가 오른쪽 끝
- **모바일:** 하단 탭 `HOME_TABS` = 홈 · 콘텐츠 · 스킬 · 마이클래스. 오른쪽 위 갤럭시 아이콘 → 화면 플립으로 갤럭시(두 손가락 확대·위아래 끌어 기울기)
- **강의 재생:** 모바일 `sceneContent()` → `openChoice()`(끝 시트) → `openSheet()`(꾹 누르기). PC는 XP 패널에 `play` 화면(`playHTML`/`bindPlay`), 끝 버튼은 패널 아래 시트, "여기까지 하고 스킬 올리기" → 같은 꾹 누르기 시트를 패널 안에(`placeSheet`)
- 첫 강의는 재생을 눌러야 시작, "이어서 다음 강의"부터 자동 재생. 무료는 연속 3개(`FREE_STREAK`) 넘으면 멤버십 안내(PC는 패널 안 `mPlace`)

## 5. 최근에 만든 것 (11-19 세션)

- 홈에서 프로필을 바꾸면 가운데 "○○ 콘텐츠로 바꾸는 중" 모달 → 홈 콘텐츠가 그 커리어용으로 교체(모달 튐 수정: 전역 `.fade` 클래스 충돌이 원인)
- 메뉴 이름 '프로필' → **마이클래스**(PC 레일·모바일 탭)
- 강의 끝 화면 PC·모바일 통일: 검은 "이어서 다음 강의" 카드 + 파란 "여기까지 하고 스킬 올리기". 잠김 카드 클래스는 `cn-lock`(전역 `.lock`과 충돌했었음)
- 콘텐츠 목록도 PC에서 스킬처럼 2단 패널로 열림
- 강의 아이콘: 유튜브형 둥근 사각형(34×24)
- **로그인 전(콜드 스타터)** 흐름
  - 메뉴는 로그인 전에도 다 보임. 마이클래스·콘텐츠·스킬을 누르면 **로그인 화면과 같은 틀의 페이지**(`gateHTML`, 제목만 메뉴별). 마이클래스는 둘러보기 없음, 콘텐츠·스킬은 "로그인 없이 둘러보기"
  - 콘텐츠 둘러보기: 스킬마다 첫 강의는 바로 수강(`freeLesson`, '무료' 표시 안 함), 나머지는 로그인 안내
  - 스킬 둘러보기(`gskills`): 커리어 키워드 검색(프로필 만들 때와 같은 검색) → 그 커리어의 스킬 목록 → 스킬 메인(`gskill`, 0P·"아직 주인이 없는 스킬")
  - 강의 끝: "○○, 아직 주인이 없어요 / 로그인하면 이 스킬과 +NP가 내 것이 돼요" + "로그인하고 내 스킬로 만들기" → 로그인 화면 제목 "○○을 내 스킬로 만들어요", "← 둘러보기"로 원래 자리 복귀
- 홈 카드의 NEW·스킬·분 태그 제거
- 대시보드 내 스킬: 필터 전체 · 탄탄한 스킬 · **키워 볼 스킬(= 추천 스킬, 아직 추가하지 않은 스킬 + 등록 버튼)**
  - 삭제: 모바일은 줄을 왼쪽으로 밀면 빨간 원형 휴지통, PC는 연필 → 체크박스 → 하나라도 체크하면 휴지통 아이콘
  - 뺀 기본 스킬은 추천으로 옮겨지고, 다시 등록하면 포인트 그대로 제자리(`wasCore`)
- 사람 화면: "○○ 님이 보고 있는 스킬"에 **나에게 없는 스킬**을 꼭 하나 넣고 이름 옆 파란 표시(맨 위)
- PC 강의 끝: 버튼이 모바일처럼 패널 아래 시트로, "여기까지 하고 스킬 올리기" 뒤 모바일과 같은 꾹 눌러 업데이트

이전 세션 주요 이력은 `git log --oneline -- next-one` 참고(갤럭시 깊이 정렬, 빅뱅, 코인 플립, 모바일 갤럭시, 두 손가락 확대·기울기, 함께 키우는 사람들 목적지 분포 등).

## 6. 열린 것 / 다음 후보

- 로그인 전 PC 오른쪽 갤럭시는 **단계**로 부름: **0단계 'sample'(현재: 샘플 갤럭시 흐리게)** · 1단계 'live'(스킬 별에서 업데이트 말풍선) · 2단계 'people'(사람 프로필들이 떠 있고 한 명씩 커지며 말풍선, 배경 별만 흐름). index.html Galaxy 안 `const GUEST_GALAXY`로 전환
- 로그인 전에 들은 강의 포인트를 로그인 후 이어서 쌓아 줄지 미정(지금은 버림)
- 로그인 전 무료 강의 범위: 지금은 "스킬마다 첫 강의". 운영 무료 목록으로 바꿀지 미정
- 데이터 PM·서비스 기획자 외 커리어의 스킬·강의 제목은 jobs.js 키워드로 만든 임시값
- `next-one/cold-start-skills.md`: 콜드 스타터 스킬 메뉴 초기 제안서(이후 사용자가 정한 흐름으로 대체됨, 참고용)

# 콜드 스타터(로그인 전) 스킬 메뉴 제안

> 대상: 로그인하지 않은 첫 방문자 · PC와 모바일 공통 · 2026-11-19 초안

## 1. 이 화면이 해야 할 일

로그인 전 사용자는 아직 목표 커리어도, 내 스킬도, 포인트도 없어요. 그래서 스킬 메뉴는 "내 것"을 보여 줄 수 없어요. 대신 **이 서비스가 어떻게 커리어에 다가가게 해 주는지**를 30초 안에 맛보게 해야 해요.

- **보여 줄 것:** 커리어 하나를 정하면 → 거기에 쓰이는 스킬이 보이고 → 스킬은 짧은 강의로 올라간다는 흐름(콘텐츠 → 스킬 → 커리어).
- **얻을 것:** 사용자가 고른 커리어를 그대로 들고 로그인으로 넘어가요. 로그인 후 프로필 만들기에서 다시 고르지 않아도 돼요.
- **피할 것:** "몇 % 갖췄어요" 같은 판정, 지금 직업을 묻는 질문, 빈 숫자(0P)를 크게 보여 주는 것.

## 2. 추천안: 커리어로 찾아보는 스킬 미리보기

검색으로 커리어를 고르면, 그 커리어에 쓰이는 스킬을 미리 보여 줘요. 내 포인트 자리는 비워 둬요.

### 화면 흐름

1. **첫 화면 (스킬 탭)**
   - 제목: "어디로 달려 보고 싶나요?"
   - 키워드 검색창: "관심 있는 일을 적어 보세요 (예: 데이터, 기획, 엑셀로 보고서)"
   - 아래 칩: 지금 많이 찾는 커리어 4~6개 (데이터 PM, 서비스 기획자, 퍼포먼스 마케터 …)
   - 맨 아래: 지금 많이 키우는 스킬 Top 5 (스킬명 · 키우는 사람 수). 검색 전에도 빈 화면이 아니게 해요.
2. **커리어를 고르면 (같은 칸에서 바뀜)**
   - 한 번의 놀람: "26,559개 스킬 중 **서비스 기획자**에게 쓰이는 스킬 **12개**를 찾았어요"
   - 스킬 목록: 스킬명 · 강의 수 · 함께 키우는 사람 수. 오른쪽 포인트 자리는 회색 막대(블랭크)로 둬요.
   - 연결의 발견 한 줄: "이 중 7개는 **데이터 PM**에도 쓰여요"
   - 하단 고정 버튼: **"서비스 기획자로 달려 보기"** → 로그인 → 이 커리어로 프로필이 바로 만들어져요.
3. **스킬을 누르면 (PC는 두 번째 패널, 모바일은 다음 화면)**
   - 스킬 설명 한 줄 · 이 스킬이 쓰이는 커리어들
   - 올릴 수 있는 강의 목록: 첫 강의는 바로 재생돼요. 나머지는 누르면 로그인 안내가 떠요(지금 콘텐츠 탭과 같은 규칙).
   - 함께 키우는 사람들: "같은 스킬, 다른 목적지" 칩만 보여 줘요(사람 목록은 로그인 후).
   - 하단 버튼: **"로그인하고 내 스킬로 등록"**

### 왜 이 안인가

- 서비스의 컨셉 그대로예요. 키워드로 커리어를 찾고 → 목표로 두고 → 스킬로 거리를 좁혀요.
- 온톨로지가 빛나는 세 순간 중 두 가지를 로그인 전에 써요: **규모의 놀람**(스킬 N개 찾음), **자유 입력 알아듣기**(내 말로 검색).
- 로그인 버튼이 "로그인"이 아니라 "이 커리어로 달려 보기"라서, 로그인할 이유가 분명해요.
- 지금 있는 화면(스킬 찾기 목록, 스킬 상세, 함께 키우는 사람들)을 대부분 다시 써서 만들기 쉬워요.

## 3. 다른 안 (비교용)

| 안 | 내용 | 좋은 점 | 아쉬운 점 |
|---|---|---|---|
| **A. 커리어로 스킬 미리보기 (추천)** | 위 내용 | 컨셉과 같음 · 로그인으로 자연스럽게 연결 | 검색 결과 품질이 중요 |
| B. 인기 스킬 랭킹 | 지금 많이 키우는 스킬 · 이번 주 급상승 | 만들기 가장 쉬움 · 둘러보기 좋음 | 개인화가 없어 "나와 무슨 상관?"이 남음 |
| C. 샘플 갤럭시 둘러보기 | 다른 사람(예: 서비스 기획자로 달리는 지윤 님)의 갤럭시를 구경 | 시각적으로 강함 · 갤럭시 기능 미리 체험 | 남의 데이터라 내 동기와 거리가 있음 |
| D. 30초 진단 | 질문 3개로 내 스킬을 추정 → 로그인하면 저장 | 개인화가 바로 됨 | 로그인 전에 입력을 시키는 마찰 · "지금의 나는 중요하지 않다" 원칙과 충돌 |

추천: **A를 기본으로 하고, B(인기 커리어 칩 · 인기 스킬 Top 5)를 첫 화면 빈자리 채우기로 섞어요.**

## 4. 이번에 프로토타입에 넣은 것 (참고)

- PC 왼쪽 메뉴, 모바일 하단 메뉴가 로그인 전에도 다 보여요: 홈 · 콘텐츠 · 스킬 · 마이클래스
- 마이클래스: 빈 프로필 원 + "아직 달려갈 방향이 정해지지 않았어요" + 비어 있는 칸(목표 커리어 · 내 스킬 · 남은 거리) + 로그인 버튼
- 스킬: 위 제안이 정해지기 전까지 임시 빈 화면 ("로그인하면 목표 커리어에 맞는 스킬을 보여 드려요")
- 콘텐츠: 로그인 없이 둘러볼 수 있어요. 각 스킬의 첫 강의는 바로 들을 수 있고(화면에 '무료' 표시 없음), 나머지는 로그인 안내가 떠요.
- 강의를 다 들으면 버튼이 "로그인하고 스킬 올리기"로 바뀌어요.

## 5. 정할 것

1. 로그인 전에 들을 수 있는 강의 범위: 지금은 "스킬마다 첫 강의"예요. 운영에서 정한 무료 강의 목록으로 바꿀지 정해야 해요.
2. 로그인 전에 들은 강의의 포인트: 로그인하면 그 스킬에 이어서 쌓아 줄지(추천), 버릴지.
3. 로그인 전 갤럭시(PC 오른쪽): 지금은 기본 샘플(데이터 PM)이 보여요. 비워 둘지, C안처럼 샘플임을 밝히고 보여 줄지.
4. 검색으로 못 찾은 키워드: 가까운 커리어 2~3개를 제안할지, 직접 입력한 말로도 목표를 만들 수 있게 할지.

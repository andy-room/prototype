# HU 리뉴얼 v3

> `../hu-renewal-v2/`(V2 톤 + V1 구조, 2026-11-27 확정 보관)를 복사해 **톤을 다시 잡는** 작업 폴더. 구조·화면·콘텐츠는 V2와 같고 톤만 바꾼다.


HU 리뉴얼의 새 시안 작업 폴더. 2026-11-27에 빈 뼈대로 시작했다.

## 배경

- 기존 HU 리뉴얼 페이지(`../hu-renewal/`)의 디자인은 쓰지 않는다. 그 폴더는 이전 시안으로 보존하고 수정하지 않는다.
- 새 컨셉을 정하고, 그 컨셉에 맞게 화면과 내용을 새로 구성한다. 컨셉이 정해지면 이 문서의 「컨셉」 절에 적는다.
- **진행 순서: 디자인 컨셉·톤앤매너를 먼저 정하고, 기획 히스토리(Confluence HU 관련 문서)는 그다음에 입힌다.** 컨셉이 정해지기 전에는 히스토리 문서를 참고하지 않는다(2026-11-27 사용자 지시).

## 스킬 갤럭시

- **스킬 갤럭시 = `skill-galaxy-v2/index.html#me` 화면을 iframe으로 넣는 것**으로 본다(2026-11-27 사용자 지정). V3에서의 경로: `../../skill-galaxy-v2/index.html#me`. 갤럭시를 새로 그리지 않는다.
- **홈(`#home`·`#guest`) 콘텐츠 영역 맨 위를 갤럭시가 화면 높이만큼 채운다**(`<section id="gx">`, `#view` 밖에 두어 하트·접기 등으로 다시 그려도 갤럭시가 다시 불러와지지 않음). 추천 섹션은 그 아래로 스크롤.
- 갤럭시 설정(`localStorage` `skill-galaxy-settings-v1`)을 열기 전에 맞춘다: 로그인 홈 = `auth:true` · 목표 `c3`(콘텐츠 마케터) · 가진 스킬 3개(없을 때만), 비로그인 홈 = `auth:false`. 갤럭시는 자체 샘플 데이터(언론·콘텐츠 분야 커리어 8개)라 V3 마이커리어(서비스 기획자 등)와 이름이 다르다.
- 같은 출처라 iframe 안을 건드린다: 겹치는 것(갤럭시 로고·검색·달라진 점·로그인 버튼·내 프로필 카드)은 숨기고, 갤럭시의 "로그인하고 시작하기"·로그인 창은 V3 `#login`으로 보낸다.
- **갤럭시 → 대시보드 연동**: 갤럭시 오른쪽 패널(`#ptop`)과 내 프로필 카드(`#meCard`)를 MutationObserver로 읽어 대시보드의 "스킬 갤럭시 · 지금 보는 곳"(노드 종류·이름·숫자)과 "지금 수준"의 목표 커리어·가진 스킬·목표까지를 바꾼다. 다른 화면에서는 "마지막으로 본 곳"으로 남는다(`localStorage` `hu-v3-gx`).

## 30차 조정 (2026-11-27 · 모바일·태블릿 시트 깨짐 수정, 화면별 점검)

- **시트가 깨지던 원인**: PC 패널의 `align-self:start`가 태블릿·모바일에도 남아, 화면에 고정한 패널이 내용 높이만큼 커지면서 위쪽 바 위로 밀려 올라가고 아래(관심·수강 신청)가 화면 밖으로 나갔음 → 덮는 모드에서는 정렬을 기본(stretch)으로. 이제 모바일 64~812, 태블릿 76~화면 끝에 정확히 들어감.
- GitHub Pages에 올라가 있는 버전은 아직 이 반응형 작업 전이라, 휴대폰으로 본 시트는 위가 잘리고 아래 탭이 시트를 덮는 옛 상태였음.
- 모바일 시트: 머리(손잡이 줄)를 아래로 끌면 닫힘, 시트·서랍·갤럭시 전체 화면이 열리면 뒤 페이지 스크롤을 멈춤, 내용을 내리면 머리 아래에 선, 좌우 여백 16, 스킬·커리어 아이콘 칸은 낮게(96).
- 모바일 목록(콘텐츠·프리미엄·검색·마이클래스): 카드 2열 — 제목 2줄·분류·시간·차시·평점·가격은 PC와 같이 모두 표시. 마이클래스 진도 %는 한 번만.
- 마이클래스 안내 문구: PC 외에는 "프로필을 누르면 마이 대시보드에서 학습 현황을 함께 볼 수 있어요".
- 모바일 온보딩·마이커리어: 위 그림 높이 150으로 낮춤.
- 태블릿 세로: 갤럭시 칸을 화면 높이의 64%로(갤럭시 안 아래 시트가 지도를 덜 가리게).
- 확인: 앱 안 브라우저의 휴대폰(375×812, 터치·모바일 UA)·태블릿(768×1024, 1024×768) 흉내 화면. iPhone·iPad 시뮬레이터는 이 Mac에 Xcode가 없어 쓰지 못함.

## 19차 조정 (2026-11-27 · 로그인 흐름 고급화)

- **로그인·시작하기·마이커리어 = 두 칸 화면**: 왼쪽은 어두운 우주 바탕에 스킬·콘텐츠·커리어 관계도(빛 점이 흐름) + "배운 만큼 성장이 눈에 보이는 HU" + 단계 표시(로그인 → 시작하기 → 마이커리어 → 내 갤럭시), 오른쪽은 흰 바탕 입력(로고·큰 제목·입력 칸·버튼). 휴대폰은 위아래로
  - 시작하기: 갤럭시 기호 엠블럼 + 혜택 3줄(맞춤 콘텐츠·필요한 스킬·커리어 지도) + 같은 높이의 '나중에 하기 | 시작하기'(버튼 어긋남 수정)
  - 마이커리어: 고른 커리어·제안 칩에 깃발 기호, '이전 | 내 갤럭시 만들기'
- **홈 만들기(#building) = 갤럭시가 자라나는 모션**: 어두운 화면 가운데 '나' 사진에서 커리어(깃발) → 스킬(번개) → 콘텐츠(재생) 노드가 선을 그리며 차례로 뻗어 나가고 궤도가 천천히 돈다. 아래 진행 막대와 4단계 체크, 끝나면 홈으로

## 컨셉 (`concepts.html`, 검토 중)

세 가지 화면 구조 제안. 톤앤매너와 섞어서 쓸 수 있다.

- 01 궤도: 보고 있는 강의를 중심에 두고 스킬·강의·커리어가 거리 순으로 둘러싼다(목업에서 강의를 누르면 중심이 바뀐다)
- 02 스킬 도감: 스킬을 도감처럼 채우고, 강의는 이번 주 퀘스트가 된다
- 03 질문: 질문 하나로 시작해 스킬 설명 → 강의 → 학습 플랜 → 커리어로 답한다

## 규칙

- **이미지는 전부 AI 제작 강의 썸네일만 쓴다.** 다른 이미지(기존 썸네일, 스톡 사진, 일러스트)는 넣지 않는다.
- **제목은 그 썸네일 강의의 강의명을 그대로 쓴다.** AI 썸네일 안에 강의명이 그려져 있으니 글자 하나 바꾸지 않는다(`[북러닝]` 같은 말머리, `(도서 제공)` 같은 꼬리 포함).
- 강의는 `data/courses.js`의 `HU_COURSES`(7,368개)에서 과정코드로 고르고, 화면에는 `js/data.js`의 `course('과정코드')`가 돌려주는 `{ title, img }`를 짝으로 쓴다. 제목이나 이미지 주소를 손으로 적지 않는다.
- 색·크기·간격·모서리·그림자는 `css/hds-tokens.css`(HDS 토큰)에서 가져온다.

## 강의 목록 (`data/courses.js`)

- 출처: [온라인 썸네일 검수 페이지](https://hunet-global-learning.s3.ap-northeast-2.amazonaws.com/vod/output/hunet/html/thumbnail_compare/online/index.html) (`online_260514.csv`, 2026-05-14 데이터)

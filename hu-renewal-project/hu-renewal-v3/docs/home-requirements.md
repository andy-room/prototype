# HU 메인(홈)에 무엇을 보여 줄까 — Confluence 종합 (2026-09-27 ~ 11-27)

> 조사 범위: HU 프로젝트(HU1) 정책서·회의록·주간이슈, 디자인팀(HU 히스토리·업무현황), FE 구현 현황, L&D테크본부 회의, CEO-CTO 주간미팅. LPD·LABS2에는 HU 홈 관련 내용 없음.
> 전제: 11/11 리더 리뷰 이후 서비스 컨셉을 다시 검토 중(11/24 주간이슈 "HU 서비스 재구성 및 검토 — 디자인 안으로 합의"). 정책서 내용은 **현재 구현 기준**이고 리디자인으로 바뀔 수 있다.

## 1. 한 줄 결론

메인은 **"스킬 갤럭시(관계) + 나 기준 현황 + 개인화 큐레이션"** 세 가지를 보여 줘야 한다. 정책서의 섹션 구성은 큐레이션 재료로 쓰고, 리더 피드백대로 **스킬 온톨로지를 전면에**, **정적 리스트·면적 마케팅은 줄이고**, **'나'를 중심에** 두는 방향.

## 3. 리더·팀 피드백 (방향)

- **부사장**: 새롭지 않다 / **스킬 온톨로지를 완전 전면에** / 홈의 넓은 3단 카드 등 **면적으로 하는 마케팅 지양** / **변화 데이터 없는 정적 리스트는 빼라** / 경계선이 없어 밋밋, 폰트가 크고 위계 불일치 / 상세는 사이드 패널
- **이상호 소장**: 스킬·콘텐츠 페이지를 **대시보드·서브홈처럼 섹션형**으로 / 스킬은 **문장형 AI 검색**("팀장한테 필요한 스킬이 뭐야?")
- **민관님**: 갤럭시를 메인으로
- **이준호 팀장(11/25)**: **갤럭시에서 내 위치 = 마지막으로 학습한 곳** / 연관도를 보여 줄 방법은 갤럭시뿐, 줄이지 말 것 / 온톨로지를 벗어나지 말 것
- **디자인팀 총평**: 어드민 목업 같다, 호기심을 끄는 시각 요소·뎁스 부족, 스킬 베이스드 러닝이 안 보인다 / 진입점부터 관심사에 맞춰 / "모든 서비스 요소에 스킬을 녹여야"
- **게이미피케이션 요구**: 리워드·성취감이 보여야(정호님) / 디자인 2안: 캐릭터 성장(새내기~리드), 스킬 카드(상위 N%·공유), 스킬 배지 / 별 모으기·컬러 채우기
- **콜드 스타트 관점**: 콜드 스타트보다 **'나' 기준으로 구성**하되, 내가 고른 것만 보이면 마이클래스가 되니 **엮이는 정보도 함께**

## 5. V3 메인에 적용한다면 (제안)

> 여기서 말하는 스킬 갤럭시는 `skill-galaxy-v2/index.html#me` 화면을 iframe으로 넣은 것이다.

V3 틀(LNB │ 마이 대시보드 고정 │ 콘텐츠)은 3·4의 쟁점을 자연스럽게 나눠 담을 수 있다.

1. **마이 대시보드(두 번째 패널) = '나' 기준** — 프로필·마이커리어, 스킬 포인트와 **상위 N%**, 마이 스킬 채움(컬러 채우기), 학습 중 강의, **"갤럭시에서 내 위치(마지막 학습 노드)"** 미니맵. 성취·리워드(배지·연속 학습)도 여기로. → 쟁점 3·게이미피케이션 요구를 흡수
2. **콘텐츠 영역 최상단 = 스킬 갤럭시(관계)** — 캐러셀 슬라이드 하나가 아니라 **고정 영역**으로(정책서 §9 "갤럭시맵 30% + 과정 리스트 70%" 구조와도 맞음). 운영 배너는 갤럭시 아래 얇은 띠로 분리. → 쟁점 1·2를 "갤럭시 전면 + 배너 공존"으로 조정
3. **큐레이션 = 정책서 순서 유지, 단 '스킬 문맥'을 붙인다** — 각 섹션 제목 옆에 어떤 스킬/갭 때문에 나왔는지 표시(예: "부족한 스킬 · 데이터 시각화 −320pt"). 개인화 근거가 없는 섹션은 정책대로 내림.
4. **정적·마케팅 섹션은 압축** — 요즘 많이 보는 스킬·무료·프리미엄·HU+는 카드 4~6장 그리드 대신 **한 줄 리스트/가로 스트립**으로 줄이고, 멤버십 안내는 대시보드 하단 카드로 옮겨 면적 축소. HU+ 오리지널은 1차 제외 유지. → 쟁점 4·5
5. **검색 = 문장형 질문 입력** — 상단 검색에 "팀장에게 필요한 스킬은?" 같은 예시 질문(이상호 소장 제안). 결과는 스킬→콘텐츠→커리어 순.
6. **콜드 스타트** — 대시보드는 0 값 대신 "첫 학습을 하면 채워져요" 안내 + 마이커리어 유도, 콘텐츠 영역은 정책대로 인기 기준 채움.

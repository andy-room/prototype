## 배경

- 기존 HU 리뉴얼 페이지(`../hu-renewal/`)의 디자인은 쓰지 않는다. 그 폴더는 이전 시안으로 보존하고 수정하지 않는다.
- 새 컨셉을 정하고, 그 컨셉에 맞게 화면과 내용을 새로 구성한다. 컨셉이 정해지면 이 문서의 「컨셉」 절에 적는다.
- **진행 순서: 디자인 컨셉·톤앤매너를 먼저 정하고, 기획 히스토리(Confluence HU 관련 문서)는 그다음에 입힌다.** 컨셉이 정해지기 전에는 히스토리 문서를 참고하지 않는다(2026-11-27 사용자 지시).

## 스킬 갤럭시

- **스킬 갤럭시 = `skill-galaxy-v2/index.html#me` 화면을 iframe으로 넣는 것**으로 본다(2026-11-27 사용자 지정). V3에서의 경로: `../../skill-galaxy-v2/index.html#me`. 갤럭시를 새로 그리지 않는다.
- **홈(`#home`·`#guest`) 콘텐츠 영역 맨 위를 갤럭시가 화면 높이만큼 채운다**(`<section id="gx">`, `#view` 밖에 두어 하트·접기 등으로 다시 그려도 갤럭시가 다시 불러와지지 않음). 추천 섹션은 그 아래로 스크롤.
- 갤럭시 설정(`localStorage` `skill-galaxy-settings-v1`)을 열기 전에 맞춘다: 로그인 홈 = `auth:true` · 목표 `c3`(콘텐츠 마케터) · 가진 스킬 3개(없을 때만), 비로그인 홈 = `auth:false`. 갤럭시는 자체 샘플 데이터(언론·콘텐츠 분야 커리어 8개)라 V3 마이커리어(서비스 기획자 등)와 이름이 다르다.
- 같은 출처라 iframe 안을 건드린다: 겹치는 것(갤럭시 로고·검색·달라진 점·로그인 버튼·내 프로필 카드)은 숨기고, 갤럭시의 "로그인하고 시작하기"·로그인 창은 V3 `#login`으로 보낸다.
- **갤럭시 → 대시보드 연동**: 갤럭시 오른쪽 패널(`#ptop`)과 내 프로필 카드(`#meCard`)를 MutationObserver로 읽어 대시보드의 "스킬 갤럭시 · 지금 보는 곳"(노드 종류·이름·숫자)과 "지금 수준"의 목표 커리어·가진 스킬·목표까지를 바꾼다. 다른 화면에서는 "마지막으로 본 곳"으로 남는다(`localStorage` `hu-v3-gx`).

## 5차 조정 (2026-11-27 · 대시보드 상태·밀려 나오는 패널)

- **프로필은 왼쪽 메뉴 맨 위(홈 위).** 위쪽 바 오른쪽 '김' 동그라미는 없앴다. 로그인 전에는 기본 이미지 + '로그인'(누르면 `#login`), 대시보드는 열리지 않는다
- **마이 대시보드 상태 3가지**(`localStorage` `hu-v3-dash`): 열림(기본, 로그인하면 열림) · 크게 보기(콘텐츠 영역까지 넓혀 프로필·지금 수준·학습 현황을 위 줄에, 나머지를 흰 박스 격자로) · 접힘(왼쪽 메뉴 위로 프로필이 들어가고 메뉴가 살짝 내려감). 대시보드 오른쪽 위 ⤢/⤡ · ‹ 버튼. 접고 펼 때 프로필 사진이 두 자리 사이를 크기를 바꾸며 이동한다(`flyAvatar`). 다른 화면으로 가면 크게 보기는 풀린다. 900px 이하는 늘 열림
- **갤럭시는 기본 화면 절반 높이**, 아래 손잡이로 끌어 높이 조절 · '크게 보기' · '전체 화면'(Esc로 닫기)
- **세 개념 카드 그림은 선 하나로 단순하게.** 이미지가 오면 `INTRO_IMG`에 주소만 넣으면 된다
- **추천 커리어는 2개**("지금 시작하기 좋은 커리어")
- **커리어 아이콘 = 사원증 배지**(사람 + 목걸이 줄). 모양은 모두 같고 색만 그 커리어의 주력 스킬 군집 색(`CI`). 스킬 아이콘(`FI`)과 구분된다
- **카드는 평소 선 없이**, 마우스를 올리면 테두리 + 그림자. 아이콘 영역은 옅은 회색 면
- **카드를 누르면 그 흰 박스 오른쪽에서 정보 패널이 밀려 나오고 목록은 왼쪽으로 다시 정렬**(화면 이동 없음). 패널: 이전/다음(← → 키)·n/전체·닫기(Esc), 콘텐츠·스킬·커리어별 요약, 안의 스킬·커리어·콘텐츠를 누르면 패널 안에서 바로 바뀐다, '상세 페이지 전체 보기'. 휴대폰에서는 아래에서 올라오는 시트

## 무드 조정 (2026-11-27 3차 · 레퍼런스: Dovetail 가입·홈·연동 목록 화면)

- **왼쪽 메뉴는 아이콘 위·글자 아래의 좁은 버전(84px)이 기본**이고 더 펼치지 않는다(공간 확보)
- **오른쪽 콘텐츠 영역은 섹션마다 넓은 흰 박스 하나**로 묶는다(카드마다 흰 상자를 따로 두지 않음). 목록 화면은 필터 + 목록을 한 박스에
- **목록 카드**: 위 이미지/아이콘 영역 → 얇은 구분선 → 제목·설명 → 아래 줄(시간·평점 / 가격). 테두리는 아주 옅게(`--soft`). 썸네일 위에는 아무것도 얹지 않는다
- **스킬·커리어 카드 = 아이콘 + 제목 + 설명.** 스킬 군집(TAG 그룹 20개)마다 플랫 아이콘 하나(`FAM_IC`), 커리어는 첫 번째 군집 아이콘. 상세 화면 위쪽도 같은 아이콘
- **홈의 세 개념 카드**: 검은 그림 카드 3장(01 스킬 · 02 콘텐츠 · 03 커리어) — 그림은 SVG로 직접 그림(이미지 파일 아님). '닫기'로 숨김(새로고침하면 다시 보임)
- **로그인**: 흰 바탕, 위쪽 바 없이 가운데 정렬 — 검은 정사각 로고 · 제목 · 따로 떨어진 입력 칸 · 검은 버튼 · "아직 HU 계정이 없나요? 회원가입". 온보딩·마이커리어도 같은 흰 바탕(카드 상자 없음). 레퍼런스의 소셜 로그인 버튼은 넣지 않았다

## 마이 대시보드 (2026-11-27 2차)

- 맨 위 프로필: 스킬 갤럭시 가운데 '나' 이미지(`data/avatar.webp`, 비로그인은 `data/avatar-default.webp`) — 이미지 규칙의 사용자 지정 예외
- 그 아래 "지금 수준": 레벨·포인트·다음 레벨까지 막대·상위 % + 갤럭시 연동 목표 커리어·가진 스킬·목표까지
- 오른쪽 위 ‹ 버튼으로 왼쪽으로 접기(76px 레일: 펼치기 버튼·프로필 사진·세로 글씨). 접힘 상태는 `hu-v3-dash-off`에 기억. 900px 이하에서는 접기 없음
- 왼쪽 메뉴 줄 높이 56 → 44px(1200px 이하 아이콘 메뉴 68 → 60px)

## V3 톤 (2026-11-27 · 레퍼런스: AUTO ULTIMATE 차량 대여 화면)

- **세 단 고정 틀:** 왼쪽 메뉴(LNB, 선택 항목은 검은 막대) │ **두 번째 패널 = 마이 대시보드(모든 페이지에서 고정)** │ 오른쪽 회색 콘텐츠 영역(페이지마다 바뀜)
- 마이 대시보드: 프로필 · 마이커리어 알약 · 학습 현황(기간 알약 + 2×2 숫자 타일) · 학습 알림 스위치 · 학습 시간 분포 막대 · 마이 스킬 체크 · 학습 중인 강의 · 관심 목록. 비로그인은 로그인 안내 + 인기 커리어·스킬, 막 가입한 사람은 0 값과 안내 문구(콜드 스타트)
- 오른쪽: 큰 제목("7,368개 콘텐츠") → 알약 필터 → 흰 카드(위 정보 줄: 시간·평점·하트 / 가운데 AI 썸네일 / 아래 강의명·설명 + 오른쪽 가격). 상세는 오른쪽 영역 안에서 열린다
- 홈=추천 섹션, 콘텐츠=콘텐츠 목록, 스킬=스킬 카드, 커리어=커리어 카드, 마이클래스=학습 중/완료/관심/증명서, 프리미엄, 검색. 로그인·온보딩은 틀 없이 가운데 카드
- 흑백 위주(선택은 검은 테두리), 하트 빨강·별 노랑만 색. 글자 14~24
- 시안 도구 왼쪽 **V2 | V3** 버튼으로 같은 화면을 두 버전에서 번갈아 볼 수 있다(두 폴더 모두)

- 이미지 규칙(AI 강의 썸네일만) 때문에 V1의 커리어 사진·강사 사진·교안·HU+ 이미지 자리는 글자 카드로 바꿨다. 프리미엄은 AI 썸네일이 있는 MBA 과정으로 채웠다.
- 2차 시안에 있던 '가진 스킬' 온보딩 단계와 홈의 '첫 걸음' 패널은 V1에 없는 요소라 1차에서 뺐다(추가 논의 대상).

## 컨셉 (`concepts.html`, 검토 중)

세 가지 화면 구조 제안. 톤앤매너와 섞어서 쓸 수 있다.

- 01 궤도: 보고 있는 강의를 중심에 두고 스킬·강의·커리어가 거리 순으로 둘러싼다(목업에서 강의를 누르면 중심이 바뀐다)
- 02 스킬 도감: 스킬을 도감처럼 채우고, 강의는 이번 주 퀘스트가 된다
- 03 질문: 질문 하나로 시작해 스킬 설명 → 강의 → 학습 플랜 → 커리어로 답한다

## 규칙

- **이미지는 전부 AI 제작 강의 썸네일만 쓴다.** 다른 이미지(기존 썸네일, 스톡 사진, 일러스트)는 넣지 않는다.
- **제목은 그 썸네일 강의의 강의명을 그대로 쓴다.** AI 썸네일 안에 강의명이 그려져 있으니 글자 하나 바꾸지 않는다(`[북러닝]` 같은 말머리, `(도서 제공)` 같은 꼬리 포함).
- 강의는 `data/courses.js`의 `HU_COURSES`(7,368개)에서 과정코드로 고르고, 화면에는 `js/data.js`의 `course('과정코드')`가 돌려주는 `{ title, img }`를 짝으로 쓴다. 제목이나 이미지 주소를 손으로 적지 않는다.
- 색·크기·간격·모서리·그림자는 `css/hds-tokens.css`(HDS 토큰)에서 가져온다.

## 강의 목록 (`data/courses.js`)

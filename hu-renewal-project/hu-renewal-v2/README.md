# HU 리뉴얼 v2

> 2026-11-27 이 상태로 V2 시안 보관(수정하지 않음). 톤을 다시 잡는 작업은 `../hu-renewal-v3/`에서 한다.


HU 리뉴얼의 새 시안 작업 폴더. 2026-11-27에 빈 뼈대로 시작했다.

## 배경

- 기존 HU 리뉴얼 페이지(`../hu-renewal/`)의 디자인은 쓰지 않는다. 그 폴더는 이전 시안으로 보존하고 수정하지 않는다.
- 새 컨셉을 정하고, 그 컨셉에 맞게 화면과 내용을 새로 구성한다. 컨셉이 정해지면 이 문서의 「컨셉」 절에 적는다.
- **진행 순서: 디자인 컨셉·톤앤매너를 먼저 정하고, 기획 히스토리(Confluence HU 관련 문서)는 그다음에 입힌다.** 컨셉이 정해지기 전에는 히스토리 문서를 참고하지 않는다(2026-11-27 사용자 지시).

## 기준 (2026-11-27 4차 조정)

- **V2 톤앤매너를 입혀 V1의 서비스 구조·내용을 담아 본다.** V2 톤은 아직 확정이 아니라, 입혀서 새로운 그림이 나오는지 보는 단계다.
- V2 톤(레퍼런스: 선수 프로필 화면): 위쪽 텍스트 메뉴 · 페이지 머리(제목·칩) + 오른쪽 회색 정보 패널 · 밑줄 탭 · 세그먼트 · 회색 면 숫자 카드 · 파란 인사이트 박스 · 흰 패널 안의 순위 배지/상태 점/막대/선 그래프. 썸네일 위에는 아무것도 얹지 않는다.
- V1 구조(Figma `HU-project`): 메뉴 항목(홈 · 콘텐츠 · 커리어 · 스킬 · 마이클래스 · 프리미엄 · HU Plus · 기업교육 · 검색), 화면과 흐름, 섹션 순서, 콘텐츠. 새 기능은 넣지 않는다(추가 상상력은 디자인이 자리 잡은 뒤 논의).
- V1의 왼쪽 아이콘 메뉴(LNB)는 V2 톤의 위쪽 텍스트 메뉴로 표현한다. 모바일은 아래 탭바.
- 글자 크기는 **14~24만**(14 보조 · 16 본문 · 20 중요 볼드 · 24 페이지 제목·큰 숫자), 본문 최대 폭 1640px 가운데.

## 컨셉 (`concepts.html`, 검토 중)

세 가지 화면 구조 제안. 톤앤매너와 섞어서 쓸 수 있다.

- 01 궤도: 보고 있는 강의를 중심에 두고 스킬·강의·커리어가 거리 순으로 둘러싼다(목업에서 강의를 누르면 중심이 바뀐다)
- 02 스킬 도감: 스킬을 도감처럼 채우고, 강의는 이번 주 퀘스트가 된다
- 03 질문: 질문 하나로 시작해 스킬 설명 → 강의 → 학습 플랜 → 커리어로 답한다

## 규칙

- **이미지는 전부 AI 제작 강의 썸네일만 쓴다.** 다른 이미지(기존 썸네일, 스톡 사진, 일러스트)는 넣지 않는다.
- **제목은 그 썸네일 강의의 강의명을 그대로 쓴다.** AI 썸네일 안에 강의명이 그려져 있으니 글자 하나 바꾸지 않는다(`[북러닝]` 같은 말머리, `(도서 제공)` 같은 꼬리 포함).
- 강의는 `data/courses.js`의 `HU_COURSES`(7,368개)에서 과정코드로 고르고, 화면에는 `js/data.js`의 `course('과정코드')`가 돌려주는 `{ title, img }`를 짝으로 쓴다. 제목이나 이미지 주소를 손으로 적지 않는다.
- 색·크기·간격·모서리·그림자는 `css/hds-tokens.css`(HDS 토큰)에서 가져온다.

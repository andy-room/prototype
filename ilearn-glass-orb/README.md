# ilearn-glass-orb

연수원 AI Tutor(iLearn) 플로팅 버튼의 주목도 프로토타입.
유색 퀵메뉴 위에서 버튼이 얼마나 눈에 들어오는지를 색 대비 · 부양 그림자 · 반복 모션 세 축으로 비교한다.

- `index.html` 단일 파일, 외부 라이브러리 없음 (CSS/SVG만 사용)
- 등장 스토리: 구슬로 나타남(.63s) → 캡슐이 접힐 때와 같은 가속도로 .4s 동안 벌어지고, 안내 문구가 벌어진 만큼 왼쪽부터 페이드인 → 다 열리면 X 등장 → X 를 누르면 다시 구슬. 패널의 「처음 등장 다시 보기」로 반복 확인
- 배경색·안개 순환·입체 음영·그림자·부양은 펼친 캡슐과 접힌 구슬이 같은 결로 공유하고, 상단 유리 광택(`.glass::after`)만 접힌 구슬에서 보인다
- 아이런 심볼은 Figma 「iLearn UI 리뉴얼」 컴포넌트의 logo 벡터(SVG)를 CSS 마스크(`--icon-mask`)로 사용 → 색은 `--sym` 변수로 제어

처음 열었을 때 기본 설정: 서브(흰 바탕) · 흰 유리 · 흰 테두리 켬 · 부양 그림자 가벼움 · 둥실 부양 은은 · 구슬 속 움직임 은은 · 구슬로 시작해 자동으로 펼쳐짐

## 조정 포인트
- 플로팅 전체 크기: `--ilearn-scale` (현재 .88 — 구슬 64px 기준 약 56px). 안내 문구는 배율과 관계없이 화면 기준 16px
- 안내 문구 접기·펼치기: `.orb[data-open]` (`.tail` 의 `grid-template-columns` 1fr ↔ 0fr)
  - 접힘: 문구·X ease-in 으로 빠짐 → 캡슐 .36s `cubic-bezier(.86,0,.07,1)` (전체 약 .4s)
  - 펼침: 캡슐 .4s `cubic-bezier(.86,0,.07,1)` (접힘과 같은 가속도), 문구 끝 64px 페이드 마스크(`--reveal-fade`)가 끝에서 걷힘
- 로고 크기: `.icon` 60% (Figma 비율 33.09:36.24 그대로, 화면 기준 약 30×33px), 움직임 없음
- 로고 뒤 흰 빛 반사: `.sym::before` (진하기 `--sym-glow`, 기본 .85)
- 접힌 구슬 마우스 오버 시 확대: `--hover-scale` (기본 1.08, .25s)
- 유리(배경색·안개) 밝기: `--glass-bright` — 접힌 구슬 1 → 오버 1.06, 펼친 캡슐 1.06 → 오버 1.12
- 구체 색: `.orb-wrap[data-tone]` 의 `--orb-c0/c1/c2`
- 구슬 속 안개 색: `.orb-wrap[data-tone]` 의 `--mist-a/b/deep`
- 구슬 그림자: `--sh-y`, `--sh-blur`, `--sh-a`
- 둥실 부양 (`.stage[data-float]`): `--float-d`(부양 주기), `--float-y`(부양 높이)
- 구슬 속 움직임 (`.stage[data-inner]`): `--swirl-d`(안개 순환 주기) — 로고는 움직이지 않음

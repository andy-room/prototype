# ilearn-logo-motion

아이런 실행 버튼(개선안 흰 캡슐)의 **로고 모션을 직접 조정해 보는** 프로토타입.
기준 파일은 `ilearn-prototype/button.html`(`?c=4`)이며, 같은 내용을 `original.html`로 두고 위 막대의 **비교 → 기존과 나란히**로 함께 볼 수 있습니다.

- 열기: `index.html` (GitHub Pages: https://andy-room.github.io/prototype/ilearn-logo-motion/)
- 조정판 값은 그 브라우저에만 저장됩니다. 다른 사람과 맞춰 보려면 **설정 복사 → 설정 불러오기**로 주고받으면 됩니다.

## 이번에 바뀐 점

아래 수치는 1차 수정 때 값입니다. 이후 조정판에서 직접 맞춘 값이 지금 기본값이며, 맨 아래 **현재 기본값**에 정리했습니다.

| 요청 | 반영 |
|---|---|
| 질문글을 직접 입력 | 조정판 **문구 → 질문 1·2·3** (비우면 건너뜀). 마우스를 올리면 뜨는 목록에도 바로 반영 |
| 그림자가 상황마다 튐 | 그림자는 값 하나(`--shadow`)만 씀. 호버·누름·반짝·문구 바뀜·접힘 어느 과정에서도 바뀌지 않음 (기존의 반짝 그림자·호버 그림자 제거) |
| 아이콘 움직임에 가속도 | 장면마다 **가속 방식**(등속·가속·감속·가속→감속·튕김)과 공통 **가속 세기**. 회전 속도가 장면 경계에서 이어지도록 짝지음 (응축 가속 → 형성 감속, 육각형 작아짐 가속 → 별 피어남 감속…). 로고가 접힐 땐 별 → 판, 펼칠 땐 판 → 별 순서로 조금씩 늦게 따라옴(**조각 시차**) |
| 배경의 파랑·보라 구슬 느낌 | 조정판 **배경 빛**: 색 3개, 세기, 뚜렷함, 크기, 가운데 비움 + 캡슐 아래로 번지는 빛(세기·번짐·숨쉬기) |
| 배경 빛이 좌우 말고도 불규칙하게 천천히 회전 (살아 있는 느낌) | 빛 셋이 캡슐 둘레(위·아래 가장자리 포함)를 **각자 따로** 돎 — 빛마다 속도가 다르고(1 : 1.43 : 0.77) '섞어서'면 가운데 빛은 반대로 돌아, 두 빛이 마주 보며 대칭으로 도는 일이 없음. 각도·반경·떠돎·크기는 빛마다 다른 씨앗의 부드러운 잡음이라 같은 모양이 되풀이되지 않음. 조정: 한 바퀴 평균 시간, 방향, 흔들림 각도, 흔들림이 바뀌는 시간, 불규칙함, 도는 반경, 궤도에서 벗어나 떠돎, 숨쉬기 크기·주기, 아래 번지는 빛이 같이 따라갈지. **움직임 → 좌우 흐름(기존)**으로 되돌려 비교 가능 |
| 질문 세 개 연속 → "AI 튜터 iLearn" | 순환: 로고 + 이름 → 모핑 → 질문 1·2·3 연달아(말줄임표) → 이름. "아이런"은 "iLearn"으로 |
| 문구가 자연스럽게 바뀌며 폭 맞춤 | 이전 문구가 다 사라진 뒤 → 버튼 폭을 새 문구에 맞춤 → 새 문구가 올라옴. 각 시간·겹침·이동 거리·흐림 조정 가능 |
| 말줄임표 오르내림 더 빠르게 | 한 번 오르내리는 시간 1400ms → 800ms (조정판에서 속도·높이·시차 조정) |
| 육각형 회전 30% 짧게 | 육각형 회전 장면 약 590ms → 415ms |
| 별을 더 돌리고 로고로 등장 | 별 피어나며 90° + 별 회전 90° + 작아지며 150° (기존은 피어나며 70° + 작아지며 120°, 가운데는 거의 멈춤) |
| 다시 움직일 때 아래로 찌그러짐·이동 | 시작 찌그러짐 0(기존 0.1), 둥실 움직임은 장면과 상관없이 이어져서 출발할 때 위치가 튀지 않음 |

## 화면 사용법

- **위 막대**: 재생/멈춤(스페이스), 처음부터, 속도(0.1~2배), **목업(켬 / 끔)**, 반복(전체 순환 / 모핑만 / 질문만), 버튼(펼침 / 접힌 원), 마우스 올리면 질문(켬 / 끔 — 조정판 '화면'의 같은 항목과 연결), 비교(기존과 나란히)
- **목업 켬(기본)**: 연수원 메인 화면을 칸에 여백 없이 꽉 차게 깔고(데스크톱 1440px 너비 배치를 칸 너비에 맞춰 줄이고, 높이는 칸 비율대로), 버튼을 실제 사이트 자리(오른쪽 24px·아래 40px)에 실제 크기로 얹음. 원격지원 버튼도 실제 자리에 있음. 이때 '화면'의 확대·폭 기준·배경색은 쓰이지 않음(폭은 실제처럼 오른쪽 끝 고정). 기존과 나란히 보면 왼쪽도 기존 목업(기존 버튼)으로 바뀜
- **목업 끔**: 지금까지처럼 빈 배경에 버튼만 크게
- **전체 화면**(위 막대 버튼 또는 F 키): 위 막대·조정판을 숨기고 창 가득. 목업은 줄이지 않고 창 크기 그대로(실제 페이지처럼). 나가기는 Esc, 또는 화면 맨 위에 마우스를 대면 나오는 '전체 화면 나가기'
- **원격지원 버튼 자리(목업)**: iLearn 버튼과 오른쪽 끝을 맞추고 그 위로 20px 띄움 — 보이는 버튼 기준 오른쪽 24px·아래 120px (이미지 자리 오른쪽 22px·아래 110px, 기존 실제 사이트 값은 오른쪽 24px·아래 108px). 둘 다 실제 사이트처럼 스크롤바 안쪽 기준
- **로고 + "AI 튜터 iLearn" 유지 시간**(조정판 문구 칸 맨 위): 처음 머무는 시간(모핑 전), 모핑 끝나고 머무는 시간(질문 전). 이름이 보이는 총 시간(처음 + 모핑 + 질문 전)을 바로 계산해 보여 줌
- **로고 크기**(조정판 맨 위): 버튼 안 iLearn 로고 크기를 슬라이더나 24·27·30·33·36·40px 버튼으로 바로 바꿔 비교. 버튼 높이 60px와 접힌 원 크기는 그대로이고 로고(와 모핑 도형)만 커지고 작아짐
- **모핑 타임라인**(로고 모션 칸 맨 위): 장면별 길이가 막대로 보이고, 누르거나 끌면 그 순간에 멈춰서 봄. 멈춘 뒤 ← → 로 10ms씩(Shift 50ms), ▶ 누르면 거기서부터 이어서 재생
- 바꾼 값은 이름 옆에 점이 찍히고, ↺ 로 하나씩 기본값으로 되돌릴 수 있음
- 오른쪽 위 작은 표시는 지금 장면 이름

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 수정안 + 조정판 |
| `mock.html` | 목업 배경 — 연수원(아레테 아카데미) 메인 화면 복제(`ilearn-prototype/index.html`의 화면 부분). 모양은 휴넷 서버의 CSS·이미지를 불러오므로 인터넷 필요. 버튼은 없음 |
| `original-mock.html` | 기존 목업(`ilearn-prototype/index.html`, 기존 버튼 포함) — 목업을 켜고 나란히 볼 때 |
| `original.html` | 기존 버튼(`button.html` 그대로) — 목업을 끄고 나란히 볼 때 |
| `ilearn-chat.html` | 버튼을 누르면 열리는 iLearn 창 (생김새만 같게 만든 예시) |
| `assets/` | 아이런 로고 SVG |

목업 두 파일은 화면에 보이지 않는 숨은 필드(담당자 이름·전화·메일, 사용자 ID, 소속)를 비워 두었습니다. 화면 모습은 원본과 같습니다.

스킬 갤럭시 · Type 2

USGS 방식 스킬 연관도 시안

휴넷 스킬DB의 스킬 그룹을 기준(중심)과의 연관도로 보여 주는 두 가지 차트입니다. 두 페이지 모두 그룹을 누르면 그 그룹이 새 중심이 되고, 브라우저 뒤로 가기로 돌아갈 수 있습니다.

연관도 버블

원 크기 = 중심과의 연관도, 세로축 = 콘텐츠 커버리지(스킬 갭). 왼쪽 게이지로 표시 범위를 조절하고, 선택 경로가 위에 쌓입니다.

 연관 트리

중심 → 계열 → 연관 그룹 덴드로그램. 선 두께와 끝 원 크기가 연관도이며, 왼쪽에 중심 히스토리가 뎁스 구조로 쌓입니다.
